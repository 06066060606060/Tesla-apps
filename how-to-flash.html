Firmware

How to Flash

Download the firmware for your board, then flash it directly from Android or Windows. Every .bin is a Full Flash File and must be flashed at 0x0.

ANDROID

ESPFlash

Use ESPFlash-ESP32/ESP8266Flasher to flash the board from an Android phone/tablet with USB OTG.

  1. Download the correct .bin above.
  2. Connect the ESP32 to your Android device using USB OTG.
  3. Open ESPFlash and select the connected ESP32.
  4. Select the downloaded .bin firmware.
  5. Use the flash/write function and wait until the operation completes.
  6. Reconnect to the device Wi-Fi and open the dashboard.
ESPFlash supports ESP32, ESP32-S3 and several other ESP families, and can program devices over USB OTG. Always select the firmware matching your board.
WINDOWS

Espressif Flash Download Tool

For Windows, use Espressif's official Flash Download Tool User Guide.

  1. Download and launch Flash Download Tool.
  2. Select the correct ChipType for the board.
  3. Select Develop mode and UART as LoadMode.
  4. Select the supplied firmware .bin and enter 0x0 as the flash address.
  5. Select the correct COM port and a suitable BAUD rate.
  6. Start the operation with START and wait for the download to finish.
Espressif documents the standard flow as: enter download mode, select the chip and UART mode, configure the firmware path/address and COM/BAUD, then press START.
BEFORE FLASHING

Important

  • Choose the firmware that matches your hardware: AtomS3 Lite + CAN Base or LilyGO T-2Can.
  • Do not disconnect USB while the flash operation is running.
  • Keep a copy of your current firmware if you may need to restore it.
  • After flashing, verify that the board boots normally before connecting it to the vehicle CAN network.
  • All supplied .bin files are Full Flash Files and use flash address 0x0.
