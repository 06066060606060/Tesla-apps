Wiring

Reference wiring for the ESP32 CAN interfaces used by the different Tesla applications.

ESP32 / CAN Transceiver

Dedicated ESP32 builds use a CAN transceiver such as SN65HVD230 or MCP2562. The documented EU Summon Unlock configuration uses TWAI with:

CAN_TX_PIN 5
CAN_RX_PIN 6

LilyGO / T-2Can

The unified projects use two CAN interfaces.

InterfaceTransceiverFunction
CAN AMCP2515Advanced EAP / Nag Killer
CAN BTWAIEU Summon Unlock

CAN speed & termination

The documented T-2Can configurations use 500 kbps. The README warns that the two 120 Ω resistors may need to be removed because they can cause signal errors.

⚠️ CAN wiring is vehicle-specific. Follow the wiring information in the README for your exact hardware and vehicle.
