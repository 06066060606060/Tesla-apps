⚠️ These projects interact directly with a Tesla vehicle CAN bus and are intended for controlled bench testing, code review and research environments only. Do not use them on public roads or in any situation where unsafe behavior could put people or property at risk. Always verify wiring, configuration and vehicle compatibility before testing, and comply with local laws.

Applications

EU Summon Unlock

A dedicated ESP32 solution focused on restoring and extending Smart Summon-related functionality in regions affected by EU restrictions. It monitors vehicle state, uses an injection gate to avoid manual-driving injection.

Smart SummonLive Stats Wi‑Fi DashboardOTA
What it does
  • Bypasses the documented R79 EU restriction in Autopilot.
  • Expands Summon range up to ±85 m.
  • Provides TLSSC where not available.
  • Uses Parked / Summoning / AP-active state gates before injection.

Nag-killer

An ESP32-S3 based solution dedicated to reducing Autopilot driver-attention interruptions through configurable CAN behavior. It provides two operating modes, including a TSL6P-inspired burst/pause pattern.

Live StatsWi‑Fi Dashboard OTA
What it does
  • Mode A applies a fixed +1.80 Nm value with handsOn=1.
  • Mode B cycles through +1.80, +1.50, −1.50 and −1.80 Nm.
  • Uses configurable burst / pause timing.
  • Exposes configuration, live statistics and reset through the local web API.

Advanced EAP & EU-Unlock

The most feature-rich unified firmware in the collection. It combines Advanced EAP features with EU Summon Unlock on a dual-CAN LilyGO / T-2Can platform. It can manage automatic turn-signal behavior for lane changes, configurable delays, lane-change cancellation, EU restriction-related functions.

Advanced EAPAuto Lane Change Summon UnlockCAN A / B
What it does
  • Automatic turn-signal activation when the vehicle requests a lane change.
  • Configurable turn-signal delay directly from the dashboard.
  • Supports lane-change cancellation from the screen, opposite indicator or door button.
  • Provides EU Unlock functions including R79-related AP behavior and expanded Summon range.

Nag-killer & EU-Unlock

A unified dual-CAN platform combining Nag Killer and EU Summon Unlock. CAN A handles the Nag Killer side while CAN B handles Summon Unlock, providing a single hardware platform, web dashboard, runtime diagnostics and OTA update workflow instead of requiring separate devices for these two projects.

Nag KillerSummon Unlock CAN A / BOTA
What it does
  • Combines two previously separate functions in one LilyGO / T-2Can device.
  • CAN A / Party CAN is dedicated to Nag Killer.
  • CAN B / Chassis CAN is dedicated to Summon Unlock.
  • Includes TLSSC Restore and MadMax blindspot aggressiveness settings.
  • Provides a single local dashboard and OTA update workflow.
